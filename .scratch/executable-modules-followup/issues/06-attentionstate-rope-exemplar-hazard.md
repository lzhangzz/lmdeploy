# 06: AttentionState rope buffers are sized by the first-bound module only

> *This was generated by AI during triage.*

**What:** the shared per-rank `AttentionState` sizes and gates its rope
staging buffers (dynamic-rope base buffer, mrope default buffer, per-phase
rope-base slots) on the rope config of the first-bound `Attention` module,
while each module's forward uses its own rope params. All current model
builders share one attention config across layers, so the exemplar is
representative — but nothing checks that. A future model varying rope per
layer would have modules whose config differs from layer 0's read null or
garbage staging buffers. (The retired executor coerced every layer to
layer 0's config — also wrong, but self-consistent; and the split-KV
workspace was exemplar-sized on both sides of the refactor, so only the
rope staging is new coupling.)

**Direction:** cheapest correct fix: when a subsequent `Attention` module
rendezvouses onto an existing state, check its rope kernel params match the
exemplar's and fail loudly on mismatch. Sizing for the union is only needed
if per-layer rope divergence is ever actually wanted.

**Category:** bug (latent)
**Status:** needs-triage
