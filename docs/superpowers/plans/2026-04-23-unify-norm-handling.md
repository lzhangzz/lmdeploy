# Unify Norm Handling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the `Builder._add_norm_child` anti-pattern and unify every
norm in every spec behind a single `self.norm(weight)` helper; norms bind to
their parent via `parent.name = self.norm(...)` like every other child module.

**Architecture:** Add `TextModelSpec.norm(weight)` and
`TextModelSpec.qk_norm(weight, head_dim, rope_dim)` helpers; collapse
`NormBuilder.set_weight` into `_commit_tensor`; rewrite all spec call sites;
then delete the now-dead norm-specific methods on `Builder`, `AttentionBuilder`,
`MLABuilder`, and `DeltaNetBuilder`. Behavior-preserving refactor — no
C++ changes, no kernel changes.

**Tech Stack:** Python, PyTorch, lmdeploy turbomind deploy pipeline.

**Spec:** `docs/superpowers/specs/2026-04-23-unify-norm-handling-design.md`

## Testing philosophy

This is a **behavior-preserving refactor**. There is no new unit test to write
— correctness is verified by running `scripts/test_turbomind_model.py` on
representative checkpoints, as mandated by AGENTS.md. The script hard-codes
`max_new_tokens=128` with `do_sample=False`, so the ≥128-token coherence
requirement from AGENTS.md is satisfied automatically. Each migration task
runs the test on the *specific* spec it modifies. Task 8 does a final sweep
of all affected specs.

**Command form** (from `scripts/test_turbomind_model.py` — positional args,
no flags):

```bash
python scripts/test_turbomind_model.py <model_path> <cache_dir> <tp> <gpus>
# Example: python scripts/test_turbomind_model.py Qwen/Qwen3-8B /path/to/hf_cache 1 0
```

- `<model_path>` — HF-style id, e.g. `Qwen/Qwen3-8B`.
- `<cache_dir>` — local HF cache directory. The script sets `HF_HUB_CACHE`
  and `HF_HUB_OFFLINE` internally (`_set_hf_cache`), so no pre-script env
  setup is required.
- `<tp>` — tensor-parallelism degree (integer).
- `<gpus>` — comma-separated GPU indices, e.g. `"0"` for tp=1, `"0,1"` for tp=2.

Use the `model-server` MCP tools to discover inputs:

- `list_models` — enumerates locally cached checkpoints.
- `get_model_cache_path <model_id>` — returns the `<cache_dir>` to pass.

Check `get_gpu_usage` MCP tool for an empty GPU before every run. Reject
runs on a GPU that's already busy.

**Pass criterion:** the `--- response begin --- / --- response end ---`
section contains coherent human-language text (≥128 tokens are generated by
construction). Gibberish or empty text indicates a regression — AGENTS.md:
"Gibberish responses indicate a bug."

```python
    # ------------------------------------------------------------------
    # Norm factories (shared across all specs)
    # ------------------------------------------------------------------

    def norm(self, weight, *, dim=None, data_type=None):
        """Build a NormBuilder for *weight* under this spec's contexts.

        ``dim`` defaults to ``weight.shape[-1]``. ``data_type`` defaults to
        the spec's compute dtype.
        """
        cfg = make_norm_config(
            dim=dim if dim is not None else weight.shape[-1],
            data_type=data_type if data_type is not None else self._cpp_dtype(),
            norm_eps=self._norm_eps,
        )
        m = NormBuilder(cfg, self._contexts)
        m.set_weight(weight)
        return m

    def qk_norm(self, weight, *, head_dim, rope_dim):
        """Build a per-head NormBuilder that follows the Q/K RoPE layout.

        ``head_dim`` and ``rope_dim`` match the values passed to
        ``reorder_rotary_emb`` on the sibling Q/K projections.
        """
        return self.norm(reorder_rotary_emb(weight, head_dim, rope_dim))
```

import torch

import _turbomind as _tm

from ._base import Builder


def make_norm_config(*, dim, data_type, norm_eps):
    cfg = _tm.NormConfig()
    cfg.dim = dim
    cfg.data_type = data_type
