# BF16 GEMM SM80 TMA Load/Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace cp.async G2S with TMA load and vectorized S2G with TMA store in the BF16 GEMM kernel, while keeping SM80 HMMA + LDSM unchanged.

**Architecture:** Based on `bf16_gemm_sm80_pipe_epilogue.cu`. New file `bf16_gemm_sm80_pipe_tma.cu` switches smem layouts to GMMA atoms (TMA-compatible Swizzle<3,4,3>), uses TMA descriptors for bulk gmem↔smem transfers, and uses ClusterTransactionBarrier for pipeline synchronization. The kernel is launched via `cutlass::launch_kernel_on_cluster`.

**Tech Stack:** CUDA C++17, CuTe layout algebra, CUTLASS SM90 TMA atoms, SM80 HMMA tensor cores

- [ ] **Step 6: Replace pipelined main loop (Step 5, lines ~311–420)**

Replace the pipeline loop. The key changes: mbarrier wait replaces cp_async_wait, TMA copy replaces g2s_copy, and the drain condition uses `-K_PIPE_MAX` instead of `-(K_PIPE_MAX - 1)`:

```cpp
  // ---- Step 5: Pipelined main loop ----
  //
  // Producer-consumer pipeline:
  //   Producer: TMA thread (threadIdx.x == 0) issues bulk tensor loads via mbarrier
  //   Consumer: All threads read from smem via LDSM, then execute MMA
  //
  // smem_pipe_read/write track circular buffer positions.
  // The mbarrier tracks both arrival (TMA thread signals load) and transaction bytes
  // (hardware confirms bytes written to smem).

  int smem_pipe_read  = 0;
  int smem_pipe_write = K_PIPE_MAX - 1;

  Tensor tXsA_p = tXsA(_,_,_,smem_pipe_read);
  Tensor tXsB_p = tXsB(_,_,_,smem_pipe_read);

  auto K_BLOCK_MAX = size<2>(tCrA);

  // Wait for first stage before MMA starts
  if (K_BLOCK_MAX > 1) {
    ProducerBarType::wait(&producer_mbar[smem_pipe_read], 0);
    __syncthreads();
    copy(s2r_atom_a, tXsA_p(_,_,Int<0>{}), tXrA(_,_,Int<0>{}));
    copy(s2r_atom_b, tXsB_p(_,_,Int<0>{}), tXrB(_,_,Int<0>{}));
  }

  CUTE_NO_UNROLL
  while (k_tile_count > -K_PIPE_MAX)
  {
    CUTE_UNROLL
    for (int k_block = 0; k_block < K_BLOCK_MAX; ++k_block)
    {
      if (k_block == K_BLOCK_MAX - 1)
      {
        tXsA_p = tXsA(_,_,_,smem_pipe_read);
        tXsB_p = tXsB(_,_,_,smem_pipe_read);

        // Wait for TMA load to complete on the next pipe stage
        ProducerBarType::wait(&producer_mbar[smem_pipe_read], /*phase=*/0);
        __syncthreads();
      }

      auto k_block_next = (k_block + Int<1>{}) % K_BLOCK_MAX;
      copy(s2r_atom_a, tXsA_p(_,_,k_block_next), tXrA(_,_,k_block_next));
      copy(s2r_atom_b, tXsB_p(_,_,k_block_next), tXrB(_,_,k_block_next));

      if (k_block == 0)
      {
        // TMA thread issues load for next K-tile
        if (threadIdx.x == 0) {
          ProducerBarType::arrive_and_expect_tx(&producer_mbar[smem_pipe_write], tma_transaction_bytes);
          copy(tma_a.with(producer_mbar[smem_pipe_write]), tAgA(_,k_tile_next), tAsA(_,smem_pipe_write));
          copy(tma_b.with(producer_mbar[smem_pipe_write]), tBgB(_,k_tile_next), tBsB(_,smem_pipe_write));
        }

        --k_tile_count;
        if (k_tile_count > 0) { ++k_tile_next; }

        smem_pipe_write = smem_pipe_read;
        smem_pipe_read = (smem_pipe_read == K_PIPE_MAX - 1) ? 0 : smem_pipe_read + 1;
      }

      gemm(mma, tCrA(_,_,k_block), tCrB(_,_,k_block), tCrC);
    }
  }
```

Note on barrier phase: The canonical CUTLASS example uses `PipelineState` objects that track phase bits. For our simpler single-role kernel (no warp specialization), we use phase=0 throughout. This works because `ClusterTransactionBarrier::init` with count=1 means only 1 thread arrives per cycle, and `arrive_and_expect_tx` resets the barrier after each use. If phase tracking is needed (e.g., for correctness with multiple cycles), it can be added later.

```cpp
  // Shared memory
  int smem_size = int(sizeof(SharedStorage<bf16_t, bf16_t, decltype(sA), decltype(sB)>));

  // Kernel function pointer
  auto* kernel_ptr = &bf16_gemm_device<
      decltype(prob_shape), decltype(cta_tiler),
      bf16_t, decltype(sA), decltype(tmaA), decltype(s2r_atom_a),
      bf16_t, decltype(sB), decltype(tmaB), decltype(s2r_atom_b),
      bf16_t, decltype(sC_layout), decltype(tmaC), decltype(r2s_copy), decltype(dC), decltype(mma),
      Alpha, Beta>;

  // The kernel function pointer type must match the template args order:
  //   TA, SmemLayoutA, TmaA, S2RCopyAtomA,
  //   TB, SmemLayoutB, TmaB, S2RCopyAtomB,
  //   TC, SmemLayoutC, TmaC, R2SCopy, CStride, TiledMma,
  //   Alpha, Beta

  // Set shared memory attributes
  CUTE_CHECK_ERROR(cudaFuncSetAttribute(
      (void const*)kernel_ptr,
      cudaFuncAttributeMaxDynamicSharedMemorySize,
      smem_size));

  CUTE_CHECK_ERROR(cudaFuncSetAttribute(
      (void const*)kernel_ptr,
      cudaFuncAttributePreferredSharedMemoryCarveout,
      100));

  // Launch via cluster launch API (required for TMA, even with single-CTA cluster)
  cutlass::ClusterLaunchParams params = {dimGrid, dimBlock, dimCluster, smem_size};

  cutlass::Status status = cutlass::launch_kernel_on_cluster(params, (void const*)kernel_ptr,
      prob_shape, cta_tiler,
      A, tmaA, s2r_atom_a,
      B, tmaB, s2r_atom_b,
      C, sC_layout, tmaC, r2s_copy, dC, mma,
      alpha, beta);

  CUTE_CHECK_LAST();
  if (status != cutlass::Status::kSuccess) {
    std::cerr << "Error: Failed at kernel Launch" << std::endl;
  }
```
