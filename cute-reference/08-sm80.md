# SM80/SM89 (Ampere/Ada) Specifics

SM80 (Ampere) introduced cp.async for asynchronous global→shared copies and tensor core
operations for FP16/BF16/TF32/INT8/INT4. SM89 (Ada) added FP8 MMA.

## Copy Atoms

SM75 introduced `ldsm` (shared→register loads) — see [07-sm75.md](07-sm75.md).

SM80 adds `cp.async` for asynchronous global→shared copies:

| Atom | Description |
|------|-------------|
| `SM80_CP_ASYNC_CACHEALWAYS` | cp.async with cache.always |
| `SM80_CP_ASYNC_CACHEGLOBAL` | cp.async with cache.global |
| `SM80_CP_ASYNC_CACHEALWAYS_ZFILL` | cp.async cache.always + zero-fill (for partial tiles) |
| `SM80_CP_ASYNC_CACHEGLOBAL_ZFILL` | cp.async cache.global + zero-fill |

The `_ZFILL` variants handle out-of-bounds access by zero-filling instead of faulting.
Use them when tile sizes don't evenly divide the problem.

## SM80 cp.async Pipeline Pattern

The canonical SM80 GEMM mainloop from `sgemm_sm80.cu` uses a 3-stage pipeline:

```
gmem → smem (cp.async) → registers (s2r copy) → compute (MMA)
```

### Pipeline Setup

```cpp
// Copy atoms: gmem → smem (cp.async)
TiledCopy copy_a = make_tiled_copy_A(SM80_CP_ASYNC_CACHEALWAYS<16>{}, copy_layout_a, tiler);
TiledCopy copy_b = make_tiled_copy_A(SM80_CP_ASYNC_CACHEALWAYS<16>{}, copy_layout_b, tiler);

// Copy atoms: smem → registers (retiled to match MMA)
TiledCopy s2r_copy_a = make_tiled_copy_A(s2r_atom_a, mma);
TiledCopy s2r_copy_b = make_tiled_copy_B(s2r_atom_b, mma);

// Partition gmem → smem
ThrCopy thr_copy_a = copy_a.get_slice(threadIdx.x);
Tensor tAgA = thr_copy_a.partition_S(gA);   // (CPY, CPY_M, CPY_K, k)
Tensor tAsA = thr_copy_a.partition_D(sA);   // (CPY, CPY_M, CPY_K, PIPE)

// Partition smem → registers (retiled for MMA)
ThrCopy s2r_thr_a = s2r_copy_a.get_slice(threadIdx.x);
Tensor tXsA = s2r_thr_a.partition_S(sA);    // (CPY, MMA_M, MMA_K, PIPE)
Tensor tXrA = s2r_thr_a.retile_D(tCrA);     // (CPY, MMA_M, MMA_K)
```

### Prefetch

```cpp
// Start async loads for all pipes except the last
for (int k_pipe = 0; k_pipe < K_PIPE_MAX - 1; ++k_pipe) {
  copy(copy_a, tAgA(_,_,_,k_tile_next), tAsA(_,_,_,k_pipe));
  copy(copy_b, tBgB(_,_,_,k_tile_next), tBsB(_,_,_,k_pipe));
  cp_async_fence();
  --k_tile_count;
  if (k_tile_count > 0) { ++k_tile_next; }
}
```

### Mainloop

```cpp
// 3 overlapping stages per K-tile:
//   1. gmem → smem (cp.async, async)
//   2. smem → registers (s2r copy)
//   3. registers → compute (MMA)

int smem_pipe_read  = 0;
int smem_pipe_write = K_PIPE_MAX - 1;

CUTE_NO_UNROLL
while (k_tile_count > -(K_PIPE_MAX - 1)) {
  CUTE_UNROLL
  for (int k_block = 0; k_block < K_BLOCK_MAX; ++k_block) {

    if (k_block == K_BLOCK_MAX - 1) {
      // Wait for smem pipe to be ready
      cp_async_wait<K_PIPE_MAX - 2>();
      __syncthreads();
    }

    // Prefetch smem → regs for next k_block
    auto k_block_next = (k_block + Int<1>{}) % K_BLOCK_MAX;
    copy(s2r_atom_a, tXsA_p(_,_,k_block_next), tXrA(_,_,k_block_next));
    copy(s2r_atom_b, tXsB_p(_,_,k_block_next), tXrB(_,_,k_block_next));

    // Issue next gmem → smem load at k_block == 0
    if (k_block == 0) {
      copy(copy_a, tAgA(_,_,_,k_tile_next), tAsA(_,_,_,smem_pipe_write));
      copy(copy_b, tBgB(_,_,_,k_tile_next), tBsB(_,_,_,smem_pipe_write));
      cp_async_fence();
      // Advance pipes
      smem_pipe_write = (smem_pipe_write + 1) % K_PIPE_MAX;
      --k_tile_count;
      if (k_tile_count > 0) { ++k_tile_next; }
    }

    // Compute on current k_block
    gemm(mma, tCrA(_,_,k_block), tCrB(_,_,k_block), tCrC);
  }
  smem_pipe_read = (smem_pipe_read + 1) % K_PIPE_MAX;
}

// Drain remaining pipes
cp_async_wait<0>();
__syncthreads();
```

### `cp_async` Synchronization

```cpp
cp_async_fence()        // commit pending cp.async operations
cp_async_wait<N>()      // wait until at most N pending groups remain
cp_async_wait<0>()      // wait for all pending cp.async to complete
__syncthreads()         // barrier after cp_async_wait (required)
```

## Shared Memory Layouts

SM80 uses plain (non-swizzled) shared memory layouts with `cp.async`:
```cpp
auto sA_layout = make_layout(make_shape(bM, bK, bP));  // simple layout
```

For optimal performance, smem layouts should match the MMA atom's expected operand layout.
