# SM90/Hopper Specifics

SM90 introduced three major hardware features: WGMMA (warpgroup MMA), TMA (Tensor Memory
Accelerator), and thread block clusters. These are the most important primitives for
writing high-performance kernels on Hopper.

## SM90 Copy Atoms

| Atom | Description |
|------|-------------|
| `SM90_TMA_LOAD` | TMA load, 1D through 5D |
| `SM90_TMA_LOAD_MULTICAST` | TMA load with multicast to cluster |
| `SM90_TMA_STORE` | TMA store |
| `SM90_TMA_STORE_2D` | TMA store, 2D variant |
| `SM90_U32x4_STSM_N` | Store 4×32-bit regs → smem, normal layout |
| `SM90_U16x8_STSM_T` | Store 8×16-bit regs → smem, transposed layout |

## TMA (Tensor Memory Accelerator)

Hardware-managed async copy between global and shared memory.

### Host-side: Create TMA Atom

```cpp
Tensor mA = make_tensor(A, make_shape(M, K), dA);
auto sA_layout = tile_to_shape(GMMA::Layout_MN_SW128_Atom<TA>{}, make_shape(bM, bK, bP));

Copy_Atom tmaA = make_tma_atom(SM90_TMA_LOAD{}, mA, sA_layout(_, _, 0), make_shape(bM, bK));
```

### Device-side: TMA Partitioning

TMA has its own partitioner (not TiledCopy):
```cpp
auto [tAgA, tAsA] = tma_partition(tma_a, Int<0>{}, Layout<_1>{},
                                  group_modes<0,2>(sA), group_modes<0,2>(gA));
// tAgA: (TMA, k) — source tiles in global memory
// tAsA: (TMA, PIPE) — destination in shared memory
```

### Device-side: TMA Load with Barrier

```cpp
copy(tma_a.with(producer_mbar[pipe]), tAgA(_, k_tile), tAsA(_, pipe));
ProducerBarType::wait(&producer_mbar[read_pipe], read_state.phase());
```

### Device-side: TMA Store

```cpp
tma_store_fence();          // ensure smem writes visible to TMA proxy
copy(tma_store, tCsC, tCgC);
tma_store_arrive();         // initiate async store
tma_store_wait<0>();        // wait for stores to complete
```

### Multicast TMA (Cluster)

```cpp
SM90_TMA_LOAD_MULTICAST_2D::copy(..., multicast_mask);
```

### TMA Descriptor Manipulation

For dynamic shapes (grouped GEMM):
```cpp
tma_descriptor_fence_acquire((TmaDescriptor*)desc_ptr);
```

## Register → Shared Memory Stores (STSM)

Used in the epilogue to write register results to swizzled shared memory:
```cpp
SM90_U32x4_STSM_N::copy(reg_tensor, smem_tensor);  // 4x32-bit, normal layout
SM90_U16x8_STSM_T::copy(reg_tensor, smem_tensor);  // 8x16-bit, transposed layout
```

## WGMMA (Warpgroup MMA)

SM90 MMA atoms operate at the warpgroup level (128 threads = 4 warps).

### Atom Selection

```cpp
using MMA = SM90_64x64x16_F16F16F16_SS<GMMA::Major::MN, GMMA::Major::MN>;
// Extended shapes: -DCUTE_SM90_EXTENDED_MMA_SHAPES_ENABLED
```

### Warpgroup Lifecycle

```cpp
warpgroup_arrive();           // signal readiness
gemm(mma, tCrA, tCrB, tCrC); // issue MMA operations
warpgroup_commit_batch();     // commit batch
warpgroup_wait<0>();          // wait for completion

// Scale modes
GMMA::ScaleOut::Zero          // clear accumulator before accumulate
GMMA::ScaleOut::One           // accumulate into existing accumulator
```

### GmmaDescriptor

Shared memory descriptor for WGMMA operands:
```cpp
GmmaDescriptor desc;
desc.start_address_ = smem_addr >> 4;
desc.layout_type_ = GMMA::LayoutType::INTERLEAVE;
desc.leading_byte_offset_ = ...;
desc.stride_byte_offset_ = ...;
```

SM90 fragments are MMA Descriptors (views of smem), not register data:
```cpp
// No copy from smem to register needed — MMA reads smem directly
Tensor tCrA = thr_mma.make_fragment_A(tCsA);  // descriptor fragments
Tensor tCrB = thr_mma.make_fragment_B(tCsB);
```

## Cluster Operations

Thread block clusters (up to 8 CTAs sharing SMEM via multicast).

```cpp
cluster_sync();                    // barrier across all CTAs in cluster
cluster_arrive(); cluster_wait();  // non-blocking pair
block_id_in_cluster().x            // CTA index within cluster
cluster_id_in_grid().x             // cluster index in grid
cluster_grid_dims().x              // number of clusters
```

## SM90 Shared Memory Layouts

The standard 128-byte swizzle for TMA-compatible shared memory:
```cpp
auto sA = tile_to_shape(GMMA::Layout_MN_SW128_Atom<TA>{}, make_shape(bM, bK, bP));
```

## Utilities

```cpp
elect_one_sync()     // elect one thread per warp (barrier init, TMA descriptor updates)
```

## TMA Pipeline Pattern

The canonical SM90 GEMM mainloop from `wgmma_tma_sm90.cu`:

```cpp
// Initialize barriers
ProducerBarType::init(&producer_mbar[pipe], 1);       // TMA barrier
ConsumerBarType::init(&consumer_mbar[pipe], 128);     // MMA barrier (128 threads)
cluster_sync();

// Prefetch all pipeline stages
for (int pipe = 0; pipe < K_PIPE_MAX; ++pipe) {
  ProducerBarType::arrive_and_expect_tx(&producer_mbar[pipe], tma_transaction_bytes);
  copy(tma_a.with(producer_mbar[pipe]), tAgA(_, k_tile), tAsA(_, pipe));
  copy(tma_b.with(producer_mbar[pipe]), tBgB(_, k_tile), tBsB(_, pipe));
}

// Pipelined mainloop: TMA loads ahead, WGMMA consumes behind
while (k_tile_count > -K_PIPE_MAX) {
  int read_pipe = read_state.index();
  ProducerBarType::wait(&producer_mbar[read_pipe], read_state.phase());

  warpgroup_arrive();
  gemm(mma, tCrA(_,_,_,read_pipe), tCrB(_,_,_,read_pipe), tCrC);
  warpgroup_commit_batch();
  warpgroup_wait<0>();

  ConsumerBarType::arrive(&consumer_mbar[read_pipe]);
  ++read_state;

  // Issue next TMA load
  if ((warp_idx == 0) && lane_predicate) {
    int pipe = write_state.index();
    ConsumerBarType::wait(&consumer_mbar[pipe], write_state.phase());
    ProducerBarType::arrive_and_expect_tx(&producer_mbar[pipe], tma_transaction_bytes);
    copy(tma_a.with(producer_mbar[pipe]), tAgA(_, k_tile), tAsA(_, pipe));
    copy(tma_b.with(producer_mbar[pipe]), tBgB(_, k_tile), tBsB(_, pipe));
    ++write_state;
  }
  --k_tile_count;
  ++k_tile;
}
```
